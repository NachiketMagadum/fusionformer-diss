# APPENDIX A: ETHICAL APPROVAL

This dissertation is a computational study using only publicly available datasets. No human participants were involved, no personal or sensitive data was collected or processed, and no biological or medical material was used at any stage. In accordance with Brunel University's Research Ethics guidance for computer science projects that involve neither human participants nor personal data, no formal ethics application was required and no Ethical Approval letter was issued.

**Data sources.** The Skoltech Anomaly Benchmark (SKAB) is released under an open licence on Kaggle for academic use. The Server Machine Dataset (SMD) is released by Su et al. (2019) via public GitHub for research purposes. Both are cited in the References.

**Human participants and personal data.** None were involved at any stage. No interview data, questionnaire responses, or personal identifiers appear in any of the datasets used, and no human subjects were recruited.

**Conflict of interest disclosure.** Professor Xiaohui Liu, this dissertation's supervisor, is a co-author of the Fusionformer paper (Wang et al., 2025) that this dissertation reproduces and ablates. This relationship was disclosed at the start of the project. Professor Liu explicitly encouraged the independent nature of the reproduction study, including the reporting of null and negative findings that challenge the paper's own architectural claims.

**AI use.** Anthropic's Claude was used as a coding productivity aid during prototyping, in accordance with Brunel University's guidance on AI use in dissertations. All committed code was read, understood, refactored, and validated by the author before inclusion. Experimental design, hypothesis formation, metric choice, statistical testing, and interpretation of results were performed independently by the author. No AI-generated text appears in the final dissertation without human revision and validation, and no synthetic or fabricated experimental results appear anywhere in the reported numbers.

# APPENDIX B: CODE

The complete source code for this dissertation is provided as an accompanying Jupyter notebook (`fusionformer_full_project.ipynb`) submitted alongside this document, and as a modular Python package on the author's GitHub repository. The submitted code contains:

**Model implementation (paper-faithful):**

- `fusionformer_true.py` — the full paper-faithful Fusionformer implementation. Contains the segment-wise sequence embedding, multi-head segment-wise intravariable attention (MSWAA), multi-head segment-wise intervariable attention (MSWEA), the encoder-decoder stack, the discriminator, and the two ablation flags (`use_mswea`, `use_swse`) that produce the MSWEA-off and SWSE-off variants.

**Training and evaluation:**

- `train_ff_forecast_and_score_anomaly.py` — trains any variant on a specified benchmark and machine or file, and produces a Test AUROC, PR-AUC, F1-PA, and Event-F1 report.
- `train_ff_paper_hparams.py` — same training script with the paper's exact hyperparameters (d_model=256, N_enc=4, N_dec=3, L_seg=32, batch=32, 30 epochs), used for the sanity check reported in Chapter 3.6.1.
- `train_lstm_baseline.py` — the two-layer LSTM forecasting baseline used for the head-to-head comparison in Chapter 4.5.1. Same training protocol, same anomaly scoring, no attention.
- `analyse_wilcoxon.py` — reads all archived per-run results in `notes/`, produces the paired Wilcoxon signed-rank tests and Rosenthal effect sizes, and writes `notes/all_runs.csv` and `notes/wilcoxon_summary.txt`.
- `analyse_lstm_vs_ff.py` — pairs LSTM baseline runs against Fusionformer full runs by (dataset, run_id, seed) and produces the head-to-head Wilcoxon test used in Chapter 4.5.1.
- `generate_figures.py` — reads `notes/all_runs.csv` and produces the four Chapter 4 figures.

**Sweep runners:**

- `run_ablation_sweep.sh`, `run_ablation_phase2.sh`, `run_skab_sweep.sh`, `run_skab_sweep_extra.sh` — bash scripts that run one variant × dataset combination across the required (id, seed) grid.

**Data loaders:**

- `smd_loader.py` and inline SKAB loader in the training script.
- `msl_loader.py` and `fetch_msl.sh` — MSL (Mars Science Laboratory) loader used for the attempted third-benchmark sweep documented in Chapter 6.3. Two full-variant runs completed on the study hardware; the remaining twenty-five were left for future GPU work.

Every experimental number reported in Chapter 4 corresponds to a specific per-run output file in `notes/ff_true_{variant}_{dataset}_{id}_seed{N}.txt` and to a row in `notes/all_runs.csv`. Wall-clock time on the specified hardware was around 95 minutes per SMD run and under one minute per SKAB run (SKAB files are much smaller, around 500 training rows compared to SMD's 28,000). Total wall-clock time for the 48 reported runs was approximately 21 hours across the study period.

# APPENDIX C: REPRODUCIBILITY STATEMENT

Every quantitative result reported in this dissertation is reproducible from the accompanying notebook and the archived per-run output files.

**Random seeds.** Fixed at 0, 1, and 42 for the multi-seed protocol. Set via `torch.manual_seed()` and `np.random.seed()` at the start of every training script.

**Dataset paths.** Relative to the repository root. SKAB from `datasets/SKAB/data/valve1/*.csv`, SMD from `datasets/SMD/train/*.txt` and `datasets/SMD/test/*.txt` with anomaly labels from `datasets/SMD/test_label/*.txt`.

**Metric computations.** Standard scikit-learn implementations (`roc_auc_score`, `precision_recall_curve`, `f1_score`, `auc`).

**Statistical tests.** `scipy.stats.wilcoxon` with `zero_method="wilcox"` and `alternative="two-sided"`. Rosenthal effect size r computed as |Z| / sqrt(n_nonzero) where Z is derived from the two-sided p-value via the standard normal inverse cumulative distribution function.

**Raw per-run outputs archived in the `notes/` directory of the code repository.** The archive contains 48 individual result files (nine SMD full runs, nine SMD no_mswea runs, fifteen SKAB full runs, fifteen SKAB no_mswea runs), each formatted with the same fields (test AUROC, PR-AUC, anomaly rate, hyperparameter block, wall-clock time). The consolidated `notes/all_runs.csv` file contains all 48 rows in tabular form for easy re-analysis.

**Hardware.** A single MacBook Pro M5 laptop with 16 GB of unified memory, using PyTorch's Metal Performance Shaders backend. Every experiment reported in the dissertation is reproducible on this hardware.

**Deviations from the paper's exact configuration** are listed in Chapter 3.6. These affect absolute AUROC values but not the paired ablation comparison, since both the full and MSWEA-off variants use identical values of every deviated hyperparameter.
